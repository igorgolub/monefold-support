Tell us what you were trying to do, what happened, and which iPhone, iOS version and Monefold version you use. If you are using TestFlight, include the build number. You can add a screenshot with personal details hidden. Keep card numbers, passwords and backup files private.

Record a transaction

Tap + to record an expense, income or transfer. On Accounts, select an account to review its balance and transactions. Open Reports from Dashboard to see spending and income by category. Manage your own categories in Settings → Categories.

Save or restore a backup

Open Settings → Data → Backups & restore. To save a copy, tap Create backup, then Save or share backup and choose where to keep the .mfold file. The same screen lists automatic copies saved on this iPhone.

To recover your records, tap Restore a backup. Select a saved copy or use Choose from Files, then review the summary before confirming. Restoring replaces your active ledger with the selected copy. If you want to keep both versions of your records, save a copy of your current ledger first.

Check an Apple Wallet import

Open Settings → Import sources and check the status of your Wallet connection. In Shortcuts → Automation, make sure the Wallet transaction automation is enabled, the card is selected and the automation uses Import Wallet Payment. If a purchase appears in Needs attention, open it and follow the action shown there. You can record a missing purchase manually using +.

Manage App Lock

Open Settings → App Lock to change whether Monefold asks for device authentication. If iOS cannot authenticate you, check that Face ID, Touch ID or your device passcode is set up in iOS Settings.
